Honest Assessment
When to use durag. When not to.
Works well
  • Numeric behavioral columns with variance (MRR, logins, NPS, tenure)
  • Clear binary outcome column (churned/retained, converted/bounced, upgraded/free)
  • 500+ rows with 3-4+ numeric columns
  • Multiple data sources merged on a shared key
Struggles with
  • Mostly categorical data without numeric metrics
  • No clear outcome column to split on
  • Under 50 rows
  • Opaque column names (field_47 instead of nps_score)

API
findPattern()
The core function. Takes your data and a target outcome, returns the contacts that match the pattern.
const result = findPattern(
  rows,         // array of data objects
  numericCols,  // columns to analyze as features
  'churned',    // the outcome column
  'true'        // the target value to match against
)

// result
result.atRiskCount   // 43 -- contacts matching the pattern
result.atRisk        // the actual records, scored 0-100
result.signals       // ranked list of what drives the pattern
result.badCount      // 56 -- how many already hit the outcome
result.message       // human-readable summary
